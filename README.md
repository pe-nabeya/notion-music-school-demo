# Notionで作った音楽教室の受講生管理DB

紙の台帳で生徒情報を管理する音楽教室を想定し、生徒名簿、レッスン記録、講師向けの手順書をNotionにまとめました。公開デモのデータはすべて架空です。

[Notionの公開デモを開く](https://best-professor-69c.notion.site/3ebdf9a49a028052aee8f13c3b1f2092)

## 作った仕組み

- **生徒名簿**で、在籍状況、コース、担当講師、レッスン日時を管理します。「在籍中の生徒」の一覧で、現在通っている生徒を確認できます。
- **レッスン記録**を生徒名簿とリレーションでつなぎました。各生徒のレッスン回数と最終レッスン日を、名簿で自動集計します。
- **講師向けマニュアルとよくある質問**を同じページから開けるようにしました。振替、入会、休会の手順を確認できます。

## デモの見方

1. 公開デモの「生徒名簿」で「在籍中の生徒」ビューを開きます。
2. 名簿の「レッスン回数」「レッスン最終日」を見ます。画面幅によっては、表を右にスクロールします。
3. トップに戻り、「レッスン記録」で、日付と生徒をひも付ける項目を確認できます。

音楽教室の業務を想定した構築・検証事例です。
